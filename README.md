# openrust

A coding agent CLI + TUI inspired by OpenCode, written in Rust.

## Building on OpenCode

If you are working on a project that's related to OpenCode and is using "opencode" as part of its name, for example "opencode-dashboard" or "opencode-mobile", please add a note to your README to clarify that it is not built by the OpenCode team and is not affiliated with us in any way.

Si vous travaillez sur un projet lié à OpenCode et qui utilise "opencode" dans son nom, par exemple "opencode-dashboard" ou "opencode-mobile", veuillez ajouter une note à votre README pour préciser qu'il n'est pas construit par l'équipe OpenCode et n'est affilié à nous d'aucune manière.

## Installation

cargo build --release

## Usage

cargo run --bin openrust

## Configuration

opencode-rust.json or env vars
